# Task 4：Swap 之后，DeFi 还能玩什么？

> 对应课程：第四章 从零部署你的首个 Avalanche DApp（讲师：Bala）
> 作者：steven7289665382-sys

## ① 定位：我们做的 Swap 在 DeFi 里是哪一环

我理解的 Swap 就是 DeFi 里的「现货市场」，是最底层的一块积木。后面的借贷、合约最后都要靠它来换币、定价。

课程里的合约用的是 AMM，核心就一个公式 `x * y = k`。池子里放两种币，数量分别是 x 和 y，交易前后乘积不变。我往池子里放 A 币，池子就按公式吐 B 币给我，买得越多价格越贵，这就是滑点。没有买卖双方挂单撮合，池子本身就是对手方。LP 往池子里存币赚手续费，代价是承担无常损失。

我做过几年支付系统，第一次看 AMM 的感觉是：它把「做市」这件事变成了一个纯函数，谁都能调，谁都能当 LP，挺巧妙的。

## ② 梳理：DeFi 的发展进程

我大概把它分成四个阶段：

1. **稳定币（MakerDAO）**：链上要先有一个价格稳定的币，才好谈借贷和交易。Maker 让大家抵押 ETH 铸 DAI，其实已经有了「超额抵押 + 清算」的影子。
2. **DEX（Uniswap）**：解决「交易要把币存到中心化交易所」的问题。AMM 让任何币都能无许可上架，不用托管。
3. **借贷（Compound / AAVE）**：光能换币还不够，币放着不动就没收益。借贷协议让存款的人赚利息，需要资金的人抵押借钱，AAVE 还搞出了闪电贷。
4. **衍生品（dYdX / GMX）**：现货只能做多、没杠杆。永续合约让人能用保证金加杠杆，做多做空都行。GMX 最早就在 Avalanche 上，跟我们课程也算有点缘分。

后面还有收益聚合、预言机、跨链这些「组合层」。整条线看下来，每一层都是踩在前一层上面长出来的。

## ③ 回答：借贷和期货分别怎么实现

### 借贷

链上没有征信，借了钱不还也找不到人，所以只能**超额抵押**。比如我抵押 100 美元的 AVAX，最多借 70 美元的 USDC。

关键是**清算**。协议会算一个健康因子（抵押品价值 × 清算线 / 负债），币价一跌，健康因子掉到 1 以下，任何人都能来帮我还一部分债，然后打折拿走我的抵押品。一般是链下的清算机器人在盯着干这个活。

合约逻辑大致是这几个函数：

```solidity
deposit()    // 存抵押品
borrow()     // 借款前检查：借完之后健康因子还 >= 1
repay()      // 还款
liquidate()  // 健康因子 < 1 时，清算人还债并拿走抵押品 + 奖励
```

利率跟着资金利用率走，借的人多了利率就往上涨。利息不是每个用户逐个去算，而是维护一个全局的累计指数，用户交互的时候再结算。这个做法跟我们后端做批量计息的思路挺像。

### 期货（永续合约）

链上做合约要解决三件事：

- **价格从哪来**：用预言机（比如 Chainlink）。不能直接拿自己池子的实时价，一个闪电贷就能把价格砸歪，这是很多协议被攻击的原因。
- **杠杆从哪来**：保证金。存 100 USDC 开 10 倍，就是 1000 美元的仓位。亏损把保证金吃到维持线以下，就会被强平。
- **合约价怎么贴住现货价**：资金费率。合约价比现货价高，说明做多的人多，多头就定期给空头付钱，反过来也一样。靠这个把价格拉回来。

实现方式主要有两种：dYdX 是链下撮合、链上结算；GMX 是一个大池子当所有交易者的对手方，按预言机价格成交。

## ④ 展望：如果扩展我们的 DApp

如果让我给课程里的 Swap 加功能，我会先做**借贷**，比直接上合约稳一些：

1. **新增一个借贷池合约**：用户可以存 USDC、AVAX，也可以直接把我们 Swap 里拿到的 **LP Token 当抵押品**。这样 LP 不用撤流动性也能借钱。
2. **价格用 Chainlink + TWAP**：Chainlink 为主，自己交易对里的时间加权平均价做校验，两个价格偏差太大就先暂停借款。
3. **清算直接走我们自己的 Swap**：清算人拿到抵押品后在我们的池子里卖掉，还能顺便给 Swap 带来交易量。
4. **再往上做杠杆**：借贷 + Swap 组合一下，一笔交易里完成「借钱 → 换币 → 记仓位」，就有了简单的杠杆交易。等这套跑稳了，再考虑参考 GMX 做永续合约。

安全上重点防三件事：价格被操纵、重入攻击、清算不及时导致坏账。说实话，这几件事比功能本身更难做好。

**一句话总结**：Swap 解决「换」，借贷解决「借」，合约解决「杠杆和对冲」，串起这三块的是预言机和清算机制。
