# Task 4：从 Swap 到借贷与衍生品

## ① Swap 在 DeFi 中的位置

Swap 是 DeFi 的基础流动性层：它让两种链上资产无需传统订单簿和中心化做市商即可兑换。课程里的 Pangolin V2 池采用常数乘积 AMM，核心关系是 `x × y = k`。用户买入 HAHN 时向池中加入 AVAX、取走 HAHN，储备比例随之变化，价格自然上升；交易费留在池中，补偿流动性提供者。AMM 的优点是任何人都能建池、交易可组合，代价则是滑点、无常损失以及薄池容易被操纵。

## ② DeFi 的演进

第一阶段是 DEX。Uniswap 把自动做市推广开来，解决“长尾资产没有订单簿也能交易”的问题。第二阶段是借贷市场，Aave 等协议让存款人赚取利息，借款人用链上资产作抵押获得流动性，使资产不卖出也能继续使用。第三阶段是衍生品与永续合约，dYdX 等协议把杠杆、做空和风险对冲搬到链上。再往后是聚合器、稳定币、收益策略、跨链与 RWA：协议不再孤立，而是像“金融乐高”一样相互调用。与此同时，Chainlink 一类预言机成为关键基础设施，因为借贷清算和衍生品结算不能只依赖一个容易操纵的薄池价格。

## ③ 借贷和期货如何实现

借贷的核心是“超额抵押 + 动态利率 + 清算”。用户把 AVAX 等资产存入资金池获得存款凭证，再按抵押价值的一部分借出 USDC。合约根据预言机价格计算健康因子：抵押物价值乘清算阈值，再除以债务价值；当健康因子低于 1，清算人可替借款人偿还部分债务，并折价取得抵押物。这使无需信用审查的借贷仍能保持偿付能力。利率通常随资金利用率变化，用来平衡存款和借款需求。

链上永续合约不必真的在未来交割资产，而是记录仓位、保证金和盈亏。开仓时锁定保证金，预言机持续提供指数价格；标记价格变化后，合约更新未实现盈亏和保证金率，低于维持保证金的仓位会被清算。资金费率让多空双方定期付款，使永续价格靠近现货指数。关键模块包括仓位账本、保证金金库、价格预言机、资金费率计算和清算器。

## ④ 扩展课程 DApp 的方案

我会先把现有 HAHN/WAVAX Swap 扩展成一个小型超额抵押借贷模块。用户存入 WAVAX，价格读取器不直接采用当前薄池瞬时价，而使用 TWAP 或可靠预言机；按例如 70% LTV 铸造测试稳定币。合约维护每个账户的抵押物、债务、累计利息和健康因子，并提供 `depositCollateral`、`borrow`、`repay`、`withdrawCollateral`、`liquidate`。前端在交易前展示 LTV、清算价格和滑点。第二阶段再加入永续合约，并复用同一预言机与清算服务。这样从 Swap 开始，先建立可靠的价格与风险层，再逐步增加杠杆产品，避免把薄流动性现货价直接当成清算依据。
