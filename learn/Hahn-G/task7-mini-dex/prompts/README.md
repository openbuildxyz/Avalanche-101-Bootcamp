# 课上使用的 Prompt 集

这些 prompt 就是课上 Vibe Coding 演示时**直接粘贴给 AI 编程助手**（Claude Code / Cursor / Copilot 均可）的内容。
顺序对应课程章节。每个 prompt 的原则：**先给边界（spec），再要代码；先要测试，再要实现。**

| 文件 | 用途 | 对应章节 |
|---|---|---|
| `00-project-spec.md` | 第一条 prompt：把整个项目的范围、目录、接口一次讲清 | 第 1 章末尾 |
| `01-orderbook-engine.md` | 撮合引擎 + 测试 | 第 2 章演示 1 |
| `02-wallet-login.md` | MetaMask 连接 / 切链 / EIP-712 登录 | 第 3 章演示 2 |
| `03-vault-contract.md` | Vault 合约 + Foundry 测试 + 部署脚本 | 第 4 章演示 3 |
| `04-wire-up.md` | 充值监听、提现签名、前端串联 | 第 5 章 |
| `05-debug-patterns.md` | 出错时怎么追问 AI（调试 prompt 模板） | 第 5 章方法论 |
