# 模拟咖啡仓单凭证

**仅供 Bootcamp 测试，没有真实托管库存、价值担保或赎回承诺。**

| 字段 | 模拟记录 |
| --- | --- |
| 凭证 URI | `urn:bootcamp:coffee:batch-001:v1` |
| 批次 | `COFFEE-DEMO-001` |
| 资产 | 咖啡生豆 |
| 数量 | 10,000 kg |
| 单位权益 | 1 CWR = 1 kg 模拟仓单权益 |
| 保管方 | 教学模拟仓库角色（无真实机构背书） |
| 检验方 | 教学模拟独立核验角色 |
| 发行前提 | 批次入库、称重、质检、去重及证明复核 |
| 核销流程 | 核验提货申请 → 锁定权益 → 仓库交付 → 记录销毁 |

本合约仅实现 Token 发行、转移、销毁与凭证字符串记录；锁定、物流签收、保险、司法执行、KYC 和仓库接口均未实现。真实系统应把不可篡改报告哈希、签名者、签发日期、有效期、批次状态、已提货数量与链上流通量关联，并对仓库违约与重复抵押建立处理流程。
