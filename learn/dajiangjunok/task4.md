# Task4：从 Swap 到借贷与衍生品

## ① Swap 在 DeFi 中的位置

Swap 解决即时资产交换。常数乘积 AMM 用 `x*y=k` 约束两种代币的储备：买走一侧资产，会抬高继续购买的价格。流动性提供者存入资产并获得手续费，承担价格波动和无常损失。我们的 DJJ/mUSD 池按实际储备计算输出数量，成交价同时包含手续费和价格影响，不能把储备比直接当成任意数量的成交价。

## ② DeFi 的发展过程

按能力可以分为三个阶段，这不是严格的历史先后，各类协议的发展存在重叠：

- **DEX：Uniswap** 用流动性池提供代币交换，让用户直接与合约交易。
- **借贷：Aave** 汇集存款供抵押借款，存款人获得利息，借款人无需立即卖出抵押物就能取得其他资产。
- **衍生品：dYdX** 通过保证金头寸提供对冲和杠杆交易；永续合约通过资金费率推动价格接近标的参考价格。

在这些能力之上，还能组合收益管理和 RWA。协议组合提高资金使用效率，也会把预言机、流动性和坏账风险传递给其他模块。

## ③ 借贷和期货如何实现

**借贷**：用户超额抵押，合约记录抵押物、债务和累计利息。借款或提取抵押物前，用可靠价格检查账户健康度；跌破清算阈值后，清算者偿还部分债务，换取折价抵押物。实现还要处理可借余额不足、价格过期和清算后的坏账。

**期货/永续**：记录方向、开仓价、仓位、保证金和盈亏。到期期货需要结算；永续没有到期日，因此还需资金费率。开仓检查初始保证金，持仓按参考价格检查维持保证金，不足时清算。成交价格可来自订单簿或 AMM，风险定价则不能直接依赖薄流动性池的瞬时价格。

## ④ 扩展本项目的思路

先添加独立借贷模块，实现 `deposit / borrow / repay / withdraw / liquidate`。先支持一组已知代币，加入价格有效期、借款上限、清算阈值和暂停机制；前端显示抵押价值、债务与清算风险。测试价格暴跌、不同精度、利息累计和重复清算，再考虑保证金与永续仓位。当前 Task7 只有现货撮合和结算，不属于已完成的永续交易所。
