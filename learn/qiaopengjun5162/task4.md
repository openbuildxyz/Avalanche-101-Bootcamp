# Task 4：从 Swap 到借贷、期货——DeFi 的发展进程研究

> 对应课程：第四章 从零部署你的首个 Avalanche DApp（Bala）
> 作者：qiaopengjun5162

## ① 定位：我们做的 Swap 在 DeFi 里是哪一环

课程里做的是一个即时交易（Swap）DApp：用户把 Token A 换成 Token B，价格由 AMM 的恒定乘积公式 `X × Y = K` 自动决定，不需要订单簿，也不需要中心化报价方。

用我们课程里的合约举例：池子里一边是 AVAX，一边是教学币 COURSE，乘积保持常数。用户买入 COURSE 时，池子里 COURSE 变少、AVAX 变多，价格自动上升；卖出则反之。LP（流动性提供者）按份额收取手续费。

在 DeFi 版图里，这属于最底层的基础设施——**去中心化交易（DEX）**。它解决的是「资产怎么换」的问题，是所有上层金融活动（借贷、衍生品、保险、收益聚合）的流动性地基。没有 DEX，DeFi 里的资产就进不来也出不去。

## ② 梳理：DeFi 的发展进程

DeFi 的发展可以按「解决什么问题」分成几个阶段：

**阶段一：DEX / 资产交易（2018-2020）**
- 代表：Uniswap（2020 年 V2 普及）
- 解决的问题：链上资产互换。用 AMM 取代订单簿，任何人可提供流动性并赚取手续费，解决了早期 DEX 流动性不足的问题。

**阶段二：借贷协议（2020 起）**
- 代表：AAVE、Compound
- 解决的问题：让持币者「不卖币也能借钱」。超额抵押 + 清算机制，把传统银行的借贷搬上链，资金利用率大幅提升。

**阶段三：衍生品 / 永续合约（2021 起）**
- 代表：dYdX、GMX、Hyperliquid
- 解决的问题：杠杆交易与做空。把传统 CEX 的合约交易去中心化，链上保证金的透明性和用户资产自托管成为核心卖点。

**阶段四：聚合与组合（2021 至今）**
- 代表：Yearn、Curve、各类收益聚合器
- 解决的问题：把 DEX、借贷、衍生品组合成更高层的策略——自动做市、自动复投、跨协议收益优化。DeFi 从单点工具变成可组合的金融乐高。

## ③ 回答：借贷和期货分别怎么实现

### 借贷：核心机制是超额抵押 + 清算

- 借款人把资产（如 AVAX）抵押进协议，按抵押率（如 70% LTV）借出稳定币或其它资产。
- 关键约束：**超额抵押**——借出的价值必须远低于抵押品价值，保证协议在价格波动下不坏账。
- 风控闭环：当抵押品价格下跌、健康因子低于阈值时，协议触发**清算**——任何人可以替借款人还债，并获得抵押品折价作为奖励。清算人是生态里专门的套利角色。

### 期货/衍生品：核心机制是预言机 + 保证金 + 资金费率

- **预言机（Oracle）**：合约本身不知道外部价格，必须从 Chainlink 等预言机读取标记价格（mark price），作为结算依据。
- **保证金（Margin）**：开仓只需抵押一部分名义价值（如 10 倍杠杆 = 10% 保证金）。价格不利时保证金不足会被强平。
- **资金费率（Funding Rate）**：永续合约没有到期日，靠多头/空头之间的定期资金费率支付，把合约价格锚定到现货价格，解决「永续」导致的偏离问题。

## ④ 展望：如果扩展我们的 DApp

如果给课程里的 Swap 加功能，我会优先加**借贷**而不是期货，原因有二：一是课程 AMM 已有现成的价格发现（swap 成交价 + 池储备），可以复用为抵押品定价的基准；二是借贷合约结构（抵押、健康因子、清算）与课程 AMM 的安全护栏思路一脉相承，教学上更容易讲透。

技术路径设想：

1. **抵押品定价**：用池储备计算 AVAX 的参考价格（`reserveToken / reserveAvax`），或接入 Chainlink 预言机获取外部标记价格。
2. **抵押借贷合约**：新增 `LendingPool.sol`——`deposit()` 收抵押品、`borrow()` 借出资产、`healthFactor()` 计算健康因子、`liquidate()` 触发清算。
3. **与现有 AMM 联动**：清算来的抵押品通过 AMM 卖出，形成一个「借贷 + 交易」的完整闭环，正好展示 DeFi 可组合性。
4. **教学取舍**：沿用课程 AMM 的护栏风格——超额抵押比例写死、不接真实预言机价格操纵面、不加治理，保证「能跑通机制、讲得清风险」的课程定位。
